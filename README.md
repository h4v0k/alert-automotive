# Alert Automotive website

Static site for Alert Automotive (Hudson, FL), hosted on Cloudflare Workers (static assets + `src/worker.js` for the forms).

- Pages are generated by `build.py` (edit business info in the `BIZ` dict at the top, then run `python3 build.py`; output goes to `public/`).
- Forms: `appointment-request` and `fleet-inquiry` POST to `/api/submit`. The Worker emails the shop and the customer through the shop's Gmail. Set the secrets `GMAIL_USER` and `GMAIL_APP_PASSWORD` (and optional `SHOP_EMAIL`) in Cloudflare → Workers → alert-automotive → Settings → Variables and Secrets.
- Deploys: every push to `main` deploys via Workers Builds. Cloudflare doesn't charge per deploy.
- Gallery: photos load from a public Google Drive folder. Set `folderId` and `apiKey` in `assets/config.js`.
