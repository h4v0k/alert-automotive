# Alert Automotive website

Static site for Alert Automotive (Hudson, FL), hosted on Netlify.

- Pages are generated by `build.py` (edit business info in the `BIZ` dict at the top, then run `python3 build.py`).
- Forms: `appointment-request` and `fleet-inquiry` use Netlify Forms. Set email notifications in Netlify → Forms → Submission notifications.
- Gallery: photos load from a public Google Drive folder. Set `folderId` and `apiKey` in `assets/config.js`.
